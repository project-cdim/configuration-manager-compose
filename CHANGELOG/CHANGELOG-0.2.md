# Changelog 0.2

## [0.2.0](https://github.com/project-cdim/configuration-manager-compose/compare/v0.1.1...v0.2.0) - 2026-03-24

The changes from v0.1.1 are as follows:

### Features

- Added the following Vertexes to database data:
  - `Fabric`
  - `SourceFabricAdapter`
  - `DestinationFabricAdapter`

### Breaking Changes

- Replaced the `Unit` vertex with `DeviceUnit` and modified its schema and properties.
